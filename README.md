# Домашнє завдання 8 – Галерея зображень + basicLightbox

## Опис
Восьме домашнє завдання з курсу JavaScript.  
Практика створення динамічної галереї з делегуванням подій, використанням data-атрибутів, підключенням зовнішньої бібліотеки через CDN та створенням модального вікна для перегляду повнорозмірних зображень.

## Технології / стек
- JavaScript (ES6+)
- Робота з DOM (`querySelector`, `insertAdjacentHTML`, `addEventListener`)
- Делегування подій (`event delegation` на контейнері `.gallery`)
- Data-атрибути (`data-source`)
- Шаблонні рядки / динамічна розмітка
- Зовнішня бібліотека: **basicLightbox** (через CDN jsDelivr)
- Заборона поведінки за замовчуванням (`event.preventDefault()`)
- CSS (Flexbox / Grid, стилізація за макетом Figma)

## Функціонал

| Файл       | Завдання                              | Що робить                                                                                   |
|------------|---------------------------------------|---------------------------------------------------------------------------------------------|
| index.html | Структура сторінки                    | Містить `<ul class="gallery"></ul>` та підключення basicLightbox (CSS + JS через CDN)      |
| main.js    | Створення галереї                     | Динамічно генерує 9 елементів `<li class="gallery-item">` з масиву `images`                |
| main.js    | Делегування кліків                    | Прослуховує кліки на `.gallery`, отримує `data-source` великого зображення                 |
| main.js    | Відкриття модального вікна            | Використовує `basicLightbox.create()` з готовою розміткою `<img src="...">`, показує модалку |
| styles.css | Стилізація                            | Відповідність макету: картки, hover-ефекти, відступи, адаптивність                         |

## Приклади підключення basicLightbox (CDN)

У файлі `index.html`:

```
html
<!-- CSS -->
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/basiclightbox@5.0.4/dist/basicLightbox.min.css"
/>

<!-- JS (підключається в кінці body або з defer) -->
<script src="https://cdn.jsdelivr.net/npm/basiclightbox@5.0.4/dist/basicLightbox.min.js"></script>
```
## Приклади роботи

На сторінці відображається сітка з 9 фотографій (preview-версії).
При наведенні — легкий масштаб / тінь (залежить від твого CSS).
Клік по будь-якому зображенню → відкривається модальне вікно basicLightbox з оригінальною версією (original).
Клік поза зображенням або клавіша Esc → закриває модалку.
Клік по <a> не призводить до завантаження файлу завдяки e.preventDefault().
